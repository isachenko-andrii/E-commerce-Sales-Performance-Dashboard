# Панель управління ефективністю продажів електронної комерції<br>(Looker Studio)  
  
</div>  
   
## Огляд проекту  
  
Цей проект присвячений аналізу роздрібних продажів інтернет-магазину. Мета полягає в візуалізації ключових показників ефективності (KPI), виявленні тенденцій у категоріях товарів та аналізі географії замовлень для прийняття управлінських рішень.  
  
[Посилання на інтерактивну панель керування](https://lookerstudio.google.com/u/0/reporting/77b746a6-39e8-41c2-bacc-51662ee9b358)  

## Технологічний стек  
  
**Інструмент візуалізації:** Google Looker Studio
**Джерело даних:** [CSV Dataset (E-commerce transactions)](https://drive.google.com/file/d/1crbddZ7lr0ttwX_F0QUdKdPO7z__XojU)  
**Типи аналізу:** EDA, Time Series, Geospatial Analysis, Category Segmentation.  
  
## Етапи реалізації проекту  
  
Процес розробки панелі інструментів було розділено на 5 ключових етапів:  
  
**1. Визначення бізнес-цілей та KPI**  
  
На першому етапі було сформульовано питання, на які має відповісти інформаційна панель:  
  
* **Яка динаміка доходу за місяцями?**  
* **Які категорії товарів приносять найбільший прибуток?**  
* **Як розподіляються замовлення за географією та типами пристроїв?**  
* **Який відсоток замовлень успішно доставлено, а який відсоток повернуто або скасовано?**  
  
**2. Підготовка та очищення даних**  
  
Перед імпортом у Looker Studio дані було перевірено на якість:  
* **Типізація:** Перетворення стовпця order_date у формат дати для правильної побудови часового ряду.  
* **Валідація:** Перевірка стовпців price, quantity та discount на наявність аномальних значень.  
* **Створення обчислюваних полів:** Обчислення загальних значень (Total Revenue) з урахуванням знижок, якщо це не було вказано у вихідних даних.
  
**3. Розробка архітектури панелі інструментів**  
  
Я розробив логічну структуру сторінки для зручності користувача (аналітика інтерфейсу користувача):  

* **Верхній рівень:** Ключові показники (карти показників) для швидкого огляду стану справ.  
* **Середній рівень:** Тенденції (часові ряди) та розподіл за категоріями (кругові/гістограми).  
* **Нижній рівень:** Деталізація за географічним розташуванням та операційним статусом.  
  
**4. Візуалізація та розробка**  
  
Налаштування інструментів Looker Studio:  
  
* Створення інтерактивних фільтрів (за датою, країною, категорією) для глибшого аналізу даних (Drill-down).  
* Налаштування колірної схеми для швидкого візуального розрізнення статусів замовлення (наприклад, зелений для «Доставлено», червоний для «Скасовано»).
   
**5. Аналіз результатів та формулювання висновків**  
  
Заключний етап – інтерпретація графіків:  

* Визначення кореляції між типом пристрою та середнім чеком.  
* Аналіз ефективності способів оплати в різних регіонах.  
* Підготовка рекомендацій щодо оптимізації маркетингових зусиль у країнах з низьким показником AOV.  
  
## Ключові показники та візуалізації  
  
Інформаційна панель розділена на логічні блоки, які дозволяють оцінювати ваш бізнес з різних точок зору:  
  
**1. Ключові показники (Картки показників):**  
  
* **Загальний дохід:** Загальна кількість продажів.  
* **Загальна кількість замовлень:** Кількість оброблених транзакцій.  
* **Середня вартість замовлення (AOV):** Середній чек.  
  
**2. Вплив знижок: Аналіз впливу знижок на кінцеву суму.**  
  
Динаміка продажів (Часовий ряд):  
  
Лінійний графік, що відображає коливання доходу за датою, що дозволяє визначити сезонність та пікові дні продажів.  
  
**3. Аналіз категорій та продуктів:**  
  
* Розподіл продажів за категоріями (Електроніка, Товари для дому, Іграшки, Книги, Одяг).  
* Найпопулярніші продукти за доходом та кількістю замовлень.  
  
**4. Географія та поведінка клієнтів:**  
  
* **Використання пристроїв:** Аналіз пристроїв, з яких здійснювалися покупки (мобільні телефони, настільні комп'ютери, планшети).  
* **Способи оплати:** Розподіл за способом оплати (кредитна картка, PayPal, післяплата).  
  
**5. Операційні показники**
  
* Статус доставки (Доставлено, Відправлено, Очікує розгляду, Повернено, Скасовано), що є критично важливим для логістики та аналізу відтоку клієнтів.
  
## Структура даних    
  
Використаний набір даних містить такі поля:  

* **order_id, user_id:** <code>Ідентифікатори замовлення та користувача.</code>  
* **order_date:** <code>Дата транзакції.</code>  
* **category:** <code>Категорія продукту.</code>  
* **price, quantity, discount:** <code>Ціна, кількість та відсоток знижки.</code>  
* **total:** <code>Загальна сума замовлення.</code>  
* **payment_method, delivery_status:** <code>Операційні дані.</code>  
* **country, device:** <code>Функції сегментації.</code>  
  
## Ключові висновки  
  
1. Статус замовлення  
• Значна частка замовлень скасована або повернена, що знижує ефективність та дохід.  
• Успішні доставки (Доставлено) становлять менше половини транзакцій → проблеми з логістикою та досвідом клієнтів.  
  
2. Країни  
• Більшість замовлень надходить з Німеччини, Великої Британії та Індії.  
• Німеччина демонструє високий рівень скасування та повернення.  
• Індія має більше доставлених замовлень, але також багато скасованих.  
• США мають значну частку замовлень, що очікують на виконання → проблеми з виконанням.  
  
3. Категорії товарів  
• Найпопулярніші категорії: книги, іграшки, одяг, товари для дому, електроніка.  
• Книги та одяг мають високий рівень повернень.  
• Електроніка демонструє стабільну доставку, але часто очікує на виконання.  
  
4. Знижки  
• Високі знижки (>15%) не завжди стимулюють продажі → часто пов'язані з поверненнями.  
• Середні знижки (5–10%) демонструють кращий баланс між обсягом продажів та утриманням клієнтів.  
  
5. Пристрої  
• Більшість замовлень розміщуються через мобільні пристрої та комп'ютери.  
• Мобільні замовлення мають більше статусів «Очікує» та «Скасовано» → можливі проблеми з інтерфейсом користувача мобільного сайту/додатку. 
  
## Рекомендації  
  
1. Оптимізація логістики  
 • Зменшення кількості замовлень, що очікують на розгляд, та скасованих замовлень шляхом покращення процесів доставки та прозорого спілкування з клієнтами.  
  
2. Аналіз повернень  
 • Дослідження категорій з високим рівнем повернень (книги, одяг) → можлива невідповідність якості або опису.  
  
3. Стратегія знижок  
  • Перегляд політики великих знижок, яка не дає стабільних результатів.  
  • Зосередьтеся на середніх знижках (5–10%) для кращої продуктивності.  
  
4. Мобільний досвід  
 • Оптимізація мобільного інтерфейсу для зменшення кількості неповних замовлень.  
  
5. Фокус на країнах  
 • Німеччина → зменшення повернень.   
 • США → вирішення проблеми, що очікує на розгляд.  
 • Індія → підтримка позитивної тенденції доставки.
